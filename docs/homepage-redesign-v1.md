## 1. 目标

保留"忘忧居"的山水、宣纸、个人叙事，同时让首屏在不动画的情况下就能回答三件事：

1. 这是个什么样的人、主要在做什么；
2. 有哪些值得马上看的代表作品；
3. 除此之外还记录哪些创作与生活。

原则：**让图片负责氛围，排版负责高级感，内容负责辨识度。** 冲突时优先级：定位 > 作品 > 氛围动效。

## 4. 模块规格

### 4.1 导航

一级：`首页 | 创作 ▾ | 生活 ▾ | 关于 | 作品集 ↗` + 搜索图标 + 设置图标。

| 一级 | 子项 |
|---|---|
| 创作 | 文章 `/writing`、随记 `/notes`、小说 `/novels`、归档 `/archive` |
| 生活 | 相册 `/gallery`、音乐 `/music`、在做 `/doing`、留言 `/wall` |

- 桌面：`hover`/`focus` 展开轻量下拉，220ms，面板 `--panel` + `--sh-2` + `--r-md`；`Esc` 关闭；`Tab` 全可达；导航高 64–72px
- 当前页：子项命中时组标题同样高亮（`aria-current`）
- 移动（**≤1080px**，沿用现断点）：全屏抽屉，按组折叠（默认展开当前组），菜单 `max-height:70svh` 内部滚动，`body` 锁滚动
- 子页顶部加面包屑：`创作 / 文章`（14px `--faint`）
- **所有既有路由不得删除或改地址**；`/search` 与 `/` 快捷键保留

### 4.2 Hero

```
.hero              min-height: var(--hero-h)
  .hero__bg        全屏背景（保留 5 张可换）
  .hero__inner     max-width var(--maxw)；桌面 1.05fr 1fr；gap --sp-6
    .hero__lede     eyebrow / H1 / 打字机副标题 / desc / 双 CTA / 数据条
    .hero__frame    右侧画框 4:5，--r-lg，1px --line
  .hero__scroll
```

- 高度：`clamp(640px, 85svh, 900px)`
- **H1 固定**（站主定稿 ≤14 字），`--calligraphy`，`clamp(32px, 3.4vw, 52px)`，`line-height 1.25`
- 打字机降为副标题：18px、`--faint`，90ms/字、停 2600ms、删 40ms/字；光标 1px 细线不闪；仅 `min-height:1.3em` 占位防跳动
- 双 CTA：`看看作品`（主，44px、`--r-pill`、`--accent` 底白字）→ `#featured`；`了解我`（ghost）→ `/about`
- 数据条：文章/随记/照片真实数量（复用 `getHomeData()`），不写死
- 背景动效：Ken Burns 降到 **32s、scale 1.04→1.10、位移 ≤3%**；移动端关闭；噪点层 `mix-blend-mode: soft-light`
- **对比度硬规则**：左侧统一宣纸 scrim
  `linear-gradient(100deg, rgba(248,246,241,.94) 0%, rgba(248,246,241,.72) 46%, rgba(248,246,241,0) 72%)`
  5 张背景全部实测 ≥4.5:1，不得只靠 text-shadow
- 格言卡：去掉大毛玻璃，改右下窄条（左 2px `--accent` 竖线、14px `--dim`），刷新按钮 20px；或移至 03 区顶部（站主选）
- 移动：单列，背景 absolute 铺满 + scrim；H1 28px；双 CTA 各 `flex:1`、44px 高

### 4.3 精选作品（新增）

**数据**：`SiteConfig` 增可选字段
```ts
export type FeaturedProject = {
  title: string; summary: string; category: string;
  cover: string; href: string; tags: string[]; featured?: boolean; sort?: number;
};
// SiteConfig.featuredProjects?: FeaturedProject[]
```
- 默认值 `[]`；`getSite()` 里 `Array.isArray` 归一化（照 `bio/tracks/doing/facts` 的写法）
- 后台：`SiteForm.tsx` 加一段可增删排序的编辑器 + `actions/site.ts` 校验（href 必须 `/` 或 `https://`；cover 必须 `/` 开头或绝对地址）
- **不新建 Prisma 模型、不新增迁移**

**布局**
- 桌面：1 主卡（跨 2 列）+ 2 次卡（编辑式）；或 3 等分——实现时取一种，验收前定死
- 移动：单列堆叠（不用横向滑动作为唯一入口）
- 卡：封面 16:10（`--r-md`）→ 分类胶囊（`--tech` 描边 11px）→ 标题 18px serif → 摘要 14/1.7 两行截断 → tags chips（≤4，`--accent-bg`）
- 整卡可点击，hover `translateY(-4px)` + `--sh-2`，180ms
- 区标题 `03 · 精选作品`，右侧"查看全部作品 ↗" → `site.portfolioUrl`（有值才显示）
- **空态**：`featuredProjects` 为空则整块不渲染（不留空卡、不用山水图充数）

**内容要求**：3 条分别覆盖 AI/内容生产、前端/全栈、商业落地；摘要 ≤40 字，写具体动作与结果，禁止"致力于/赋能"。

### 4.4 个人简介 / 当前在做（合并为 04）

- 左：头像 96px 圆印 + `name/en` + bio 取前 3 行 + `了解我` → `/about`；GitHub/邮箱/微信/抖音只渲染已配置字段（无值不占位、不显示"待接入"提示）
- 右：`listDoings()` 最多 3 条，卡片 `min-height:168px`，底部"全部在做 →"
- 二维码 `pf-qr` 从首页移除，迁 `/about`
- 桌面 `grid 0.9fr 1.1fr`；900–1080 上下排列

### 4.5 最近创作（05）

| 卡 | 视觉 | 兜底 |
|---|---|---|
| 主卡（1 篇最新文章） | 真实 `cover` + 标题/摘要/日期/阅读时间 | 无封面→纯文字卡（左 3px `--accent` 竖线 + 衬线大标题），**不再回退 hero-bg.jpg** |
| 次卡（1–2 条文章或随记） | 随记走手账样式：左 54px 栏（细线 + 琥珀刻度点 + 日期） | — |
| 小说条目 | 有已发布章节才显示 | 空则隐藏 |

- 数据必须来自 `src/lib/content.ts`，`page.tsx` 不得直接访问 Prisma
- 数量用真实值，不写死

### 4.6 生活切片（06）

- 相册：取最近 2–4 张真实 `Photo.src` 组成 `1+2` 拼贴，4:3，`--r-md`，hover 1.02
- 音乐：复用 `NowPlaying`（高度 ≤88px、封面 48px），**不得**新建 audio 实例，切页保持播放
- 无照片 → 友好空态，不得拿默认背景冒充用户照片
- 整区桌面 ≤360px 高

### 4.7 联系与页脚（07）

- 作品集 CTA 收进页脚上方：左标题右按钮，`--void2` 底，≤200px 高
- 页脚三列：站点信息 / 栏目链接 / 已配置联系方式；沿用现有版权年份与 RSS
- 全页**只保留两个主按钮层级**（Hero 双 CTA + 页脚 CTA），其余用文字链接

## 5. 视觉规范

### 5.1 令牌

```css
/* 新增，其余沿用 global.css:6-32 现有值 */
--sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px;
--sp-5:24px; --sp-6:40px; --sp-7:64px; --sp-8:96px;
--hero-h: clamp(640px, 85svh, 900px);
--measure: 68ch;
--tech: #5b7183;          /* 分类/技术标签、细线，占比 ≤5% */
--sh-1: 0 2px 10px rgba(58,90,82,.06);
--sh-2: 0 10px 30px rgba(58,90,82,.10);
```

**职责**：`--accent` 链接/主按钮/当前导航；`--faint` 年份序号辅助；`--amber/-ink` 仅日期序号刻度；`--tech` 标签细线；`--mag` **废弃**（替换为 `--amber-ink` / `--tech` 后删除）。
同屏强调色 ≤2 种；正文对比度 ≥4.5:1（WCAG AA）。

### 5.2 版式
| 项 | 值 |
|---|---|
| 内容宽 | 1180px（`--maxw`），左右 24px / 移动 18px |
| 栅格 | 12 列，gap 24px |
| 区块间距 | 桌面 96 / 移动 64 |
| 字号 | H1 52 / H2 30 / H3 20 / 卡题 18 / 正文 15 / 辅助 13 / 标签 11 |
| 行高 | 标题 1.25，正文 1.75 |
| 圆角 | 仅 `8 / 12 / 16 / 999` |
| 阴影 | 仅 `--sh-1 / --sh-2`（大卡片默认不加阴影） |
| 图片比例 | 作品 16:10、相册 4:3、Hero 画框 4:5、文章封面 3:2 |

### 5.3 动效
时长 120 / 180–220 / 400ms；缓动 `cubic-bezier(.22,1,.36,1)`；进入动画只做一次（IO threshold .15、位移 16px）；背景与打字机同屏最多两个持续动效；`prefers-reduced-motion` 下全关（含 Ken Burns、波纹、雨线、打字机）。
